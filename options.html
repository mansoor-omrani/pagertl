PageRTL Settings

Injected on every page (only when RTL is enabled). By default it contains html { direction: rtl; } to make the page right-to-left, and pre { direction: ltr; } to keep code blocks left-to-right.

If a website already sets dir on <html> and you want to override it, use html { direction: rtl !important; }.
